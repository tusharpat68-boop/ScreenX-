# ScreenX AI - Ultimate Edition

A native Android screen recorder (Kotlin, Jetpack Compose, MediaProjection).

- **Build and install:** see `BUILD.md` (GitHub Actions is the easiest from a phone).
- **Test it:** see `TESTING.md` for the full checklist and the known limits.
- **Progress:** see `PROGRESS.md`.
- `docs/unused-reference/` holds three older audio/merge helpers that the app does not use.
  They are kept as `.txt` so they are not compiled.
